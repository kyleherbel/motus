# Example 1: a tool walkthrough with a comment ask

The plan used for the style's end-to-end test. The take is one of the repository owner's own Daily Update recordings (102.4 s, cut to 54.4 s), so the words are real speech. The plan validates and renders.

Files: `01-tool-walkthrough.words.json` (the conformed words the plan points at) and `01-tool-walkthrough.edit.json` (the plan). The assets it names (page captures and the product's own demo clips) live in the test project, not in the pack.

## Reading it

| Scene | Says | Layout | Why |
|---|---|---|---|
| s01 | the claim | desk + hook-title | the tool's own demo clips; a swap at "just" keeps the window moving |
| s02 | "a free-to-download GitHub repo called…" | full | the real repo: a box on the licence badge at "free", on the repo name at "GitHub", a whip to the README at "called" |
| s03 | "works through Apple's existing iPhone Mirroring" | desk | Apple's page, box on the heading at "iPhone" |
| s04 | "on most iPhones, Macs…" | hero | the same page closer, a box on each device as it is named |
| s05 | "take one screen and put it onto the other" | graphic `transfer` | no capture shows this; select on "one", drop on "put" |
| s06 | "one simple command in either Codex or Claude Code" | desk | the site's install section: box on the command, then on the agent line |
| s07 | "a visual of what's happening on a given screen" | hero | a phone screen: a tap, then boxes on what it reads |
| s08 | "you don't have to take screenshots…" | full | the agent's own log, three lines boxed in turn |
| s09 | "testing… automating… workflows" | behind | three real clips, one per use |
| s10 | "if you're worried about security" | desk | the site's safety section |
| s11 | "block this from… banking… wallet" | graphic `app-lock` | Bank locks on "banking", Wallet on "wallet" |
| s12 | the ask | face + comment-cta | bare face; the keyword is corrected in `text` |

## Known gaps against the guide

- Scenes average 4.5 s; the guide asks for 2 to 4 s. The take is spoken at about 215 wpm with long sentences.
- s04 is mostly dark page under the image.
- s10's crop leaves its heading off-centre.
- Every scene is `single`: this is a test plan, not a plan with options.
