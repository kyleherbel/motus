# Ribbon Depth visual study

Study date: 2026-11-15. Scope: one public 20.006-second promo containing two Violet edits, plus six public scene boards. One board presents the bright family. The actual reel is inset at 540×960 inside a 1920×1080 promo; measurements normalize by ×2. Reference media is local in ignored `corpus/` and is never shipped with the pack.

Three independent passes measured layout, type and motion. `layout.md`, `type.md`, and `motion.md` summarize them. `design.md` distinguishes visible measurements, approximate material reconstruction and original extensions. No private product code, PDF, handbook, exact numeric recipe or original audio assets were accessed.

The public moving examples differ from the fixed sequence described in the sales text: one has four scenes, another five. The style therefore preserves visual grammar without prescribing the number of scenes or a ten-second duration.

The new comparison element, four-card extension, intensity control and per-project narrative choices are original additions. Light Lime's layout has static evidence; its motion is extrapolated. The procedural ribbon recreates the visible idea but is not the original shader/renderer.

For a different brand, update the explicit tokens and verify the result. These colors, materials, card shapes and motion are specific to this reference, not Motus's global identity or Kyle's universal preferences.
